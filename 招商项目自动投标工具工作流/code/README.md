# 招商智投 · 招商项目自动投标工具工作流

面向行至集产业招商业务的投标工作流原型。把「招商线索 → 资格预审 → 招标要素抽取 → 资质匹配与报价 → 标书初稿 → 人工复核 → 提交归档」固化为可运行、可追溯、可复用的系统。

- 后端：Spring Boot 2.6.13（Java 8+）
- 前端：Vue 3 + Vite 5 + Element Plus + Pinia + Vue Router
- 存储：JSON 文件（演示版，零外部依赖）
- AI：本地模板兜底，可选 OpenAI 兼容大模型（DeepSeek 等）
- 权限：管理员 / 投标经理 / 复核风控 / 只读观察员
- 个人中心：昵称、职位、头像、手机号、邮箱、简介、密码、通知偏好、我的动态
- 协作与消息：站内消息、截止提醒、附件上传下载、项目评论、关注、复制项目
- 管理端：成员新增/编辑/启停/重置密码、资格规则配置、审计 CSV 导出
- 批量能力：Excel 模板下载、批量导入项目、批量删除、回收站批量恢复/彻底删除
- 验证：8 个后端单元测试通过，扩展 API 联调 30+ 断言通过，浏览器端无控制台错误

## 快速启动

### 1. 后端

```bash
cd backend
mvn clean package -DskipTests
java -jar target/bid-workflow.jar
```

后端地址：`http://127.0.0.1:8080/api`，健康检查：`/api/health`。

如果 8080 被占用，可换端口启动，并让前端代理指向新端口：

```bash
java -jar target/bid-workflow.jar --server.port=8081
# 前端另开终端（Windows PowerShell）
$env:VITE_API_TARGET="http://127.0.0.1:8081"; npm run dev
# macOS / Git Bash：VITE_API_TARGET=http://127.0.0.1:8081 npm run dev
```

### 2. 前端

```bash
cd frontend
npm install
npm run dev
```

打开 `http://127.0.0.1:5173`。

> 如 npm 官方源较慢，可使用 `npm install --registry=https://registry.npmmirror.com`。

### 3. 登录

| 账号 | 密码 | 角色 |
| --- | --- | --- |
| manager | Bid@123 | 投标经理 |
| reviewer | Review@123 | 复核 / 风控 |
| admin | Admin@123 | 系统管理员 |
| viewer | View@123 | 只读观察员 |

演示账号的显示名与登录名一致（`admin`、`manager`、`reviewer`、`viewer`），不使用人名。登录页已预填 `manager`，也可点击演示账号卡片切换。

## 演示路径

系统首次启动自动写入 6 个项目，覆盖：

- `BP...001` 待人工复核：完整链路、AI 初稿、复核队列
- `BP...002` 要素已抽取：等待匹配测算
- `BP...003` 资格预审驳回：硬性规则失败自动驳回
- `BP...004` 已归档：提交回执、档号、保存年限
- `BP...005` 复核退回：退回意见与重新提交
- `BP...006` 草稿：资格预审入口

建议按「工作台 → BP...003 自动驳回 → BP...002 抽取/测算 → BP...001 初稿/复核 → reviewer 复核 → BP...004 归档 → admin 规则/审计 → viewer 权限」顺序体验。

## v1.3 新增：批量导入与批量操作

- **Excel 导入模板**：提供《项目批量导入模板.xlsx》，含“项目导入模板 / 填写说明 / 字段说明”三个工作表、浅灰固定表头、行业/来源/部门下拉选项、示例行与字段注释。
- **批量导入**：项目列表、草稿箱均提供“批量导入”，读取 XLSX / CSV 后逐行校验；成功行直接进入草稿箱，失败行返回行号与原因；单次最多 200 行。
- **批量删除**：管理员在项目列表可多选批量删除；草稿负责人在草稿箱可多选批量删除；全部进入 30 天回收站。
- **回收站批量操作**：管理员可多选批量恢复或批量彻底删除。
- **模板入口**：批量导入弹窗与新建项目“智能导入”卡片均可直接下载模板。
- **导出导入结果**：批量导入完成后显示成功数、失败数、失败行号与原因，并可直接跳转草稿箱核对。
- **交互细化**：侧边栏使用 SINCIT 图形标记并保留品牌文字；右上角头像改为圆形；浏览器 favicon 同步为 SINCIT 标记；头像上传增加圆形预览、拖动与缩放裁剪；基本资料/登录安全默认卡片展示，点击后弹窗修改；工作台四个指标卡可点击跳转；新建页底部增加保存草稿/保存并发起预审；新建页改为仅提供批量导入；批量导入完成后按钮变为“查看”并自动进入草稿箱；草稿编辑取消返回草稿箱；草稿箱与消息中心操作按钮改为紧凑布局；标书语气支持下拉选择与自由输入；智能导入支持直接上传 XLSX 模板并回填第一行项目；管理员和投标经理均可选择项目负责人（投标经理限本部门）。
- **模板细节**：截止时间列设置日期有效性校验，可输入或选择日期时间；负责人列更名为“项目负责人”；管理员和投标经理均可指定项目负责人，投标经理仅能选择本部门负责人。

模板文件：[项目批量导入模板.xlsx](../doc/项目批量导入模板.xlsx)

## v1.2 新增：草稿箱、回收站与智能导入

- **账号显示名去人名化**：演示账号的显示名与登录名一致（admin / manager / reviewer / viewer），避免示例数据看起来像真实员工。
- **草稿箱**：保存草稿不再混在投标项目中，侧边栏独立“草稿箱”；只有负责人和管理员能看到草稿，避免未完成方案被其他人看到。
- **管理员删除与回收站**：管理员可删除任意项目，草稿负责人可删除自己的草稿；删除后进入回收站保留 30 天，可恢复或彻底删除，到期自动清理并同步删除附件。
- **智能导入**：新建/编辑项目支持上传 TXT、MD、CSV、DOCX、XLSX 招标文件/模板，或识别已粘贴的正文，自动回填项目名称、招标人、预算、保证金、截止时间、产业方向，并展示抽取到的要素清单与预警。
- **列表与统计口径**：投标项目列表默认排除草稿；“我关注的”筛选、仪表盘项目统计与草稿数量分别展示。

## v1.1 新增：从原型到完整工作台

- **个人中心**：修改昵称、职位、手机号、邮箱与简介；上传/恢复头像；修改密码（旧令牌立即失效）；设置 5 类消息偏好；查看个人统计与最近 20 条操作动态。
- **站内消息**：待复核任务、复核结果、截止提醒、评论、附件和状态变更统一进入消息中心；顶部铃铛未读角标、抽屉预览、全部已读、删除与按类型筛选。
- **项目协作**：附件上传/下载/删除（PDF、Word、Excel、PPT、TXT、ZIP、图片，20MB 内）；项目评论；关注项目接收动态；一键复制项目为基础信息与资格画像的新草稿。
- **成员管理**：管理员新增成员、编辑角色/部门/联系方式、启停账号、重置临时密码；不能停用自己、不能移除最后一个管理员。
- **体验细节**：全局项目搜索（Ctrl+K）、我关注的筛选、审计 CSV 导出、帮助中心、登录失败锁定、记住账号、密码强度提示、头像与角色标识。
- **安全加固**：密码策略（8-32 位且含字母数字）、令牌版本失效机制、头像/附件格式与大小校验、编辑/删除操作的权限二次校验。

## 核心能力

- **资格预审规则引擎**：10 条可配置规则，必填失败自动驳回，非必填失败预警并允许“有条件通过”。
- **招标要素抽取**：识别预算、保证金、截止时间，抽取资格、技术、商务、评分等要素，保留原文与置信度。
- **匹配与报价测算**：五维匹配评分、成本拆解、建议价区间、毛利率、价格分、中标概率与风险提示。
- **AI 标书初稿**：本地模板兜底；配置 Key 后调用大模型；失败自动降级并显式标记。
- **人工复核**：负责人不得复核本人项目；退回必须填写意见；保留多轮记录。
- **权限与审计**：角色 + 部门数据范围 + 职责分离；每个动作记录操作人、IP、TraceId 与详情。
- **并发控制**：每个动作校验 version，冲突返回 409；状态机拒绝越级操作。

## 配置 AI

`backend/src/main/resources/application.yml`：

```yaml
app:
  ai:
    provider: local            # local | openai-compatible
    base-url: https://api.deepseek.com
    model: deepseek-chat
    api-key: ""
```

也可用启动参数或环境变量：

```bash
java -jar target/bid-workflow.jar \
  --app.ai.provider=openai-compatible \
  --app.ai.api-key=sk-xxx
```

支持 `APP_AI_PROVIDER` / `APP_AI_API_KEY` / `APP_AI_MODEL` / `APP_AI_BASE_URL` 环境变量。

未配置 Key 或调用失败时自动使用本地模板，不影响流程。

## 已知边界

当前为可运行原型：JSON 存储、HMAC 令牌、文本/DOCX/XLSX 导入识别、本地模板生成；附件存储在本机 `backend/data/uploads`，头像存储在 `backend/data/avatars`。PDF 暂不支持直接解析，需复制正文后粘贴识别。生产化需接入 MySQL、SSO、PDF/OCR、真实大模型、对象存储、电子签章与交易平台，并完成等保与数据合规评估。详见《技术架构与安全合规说明》与《功能说明与操作手册》。
